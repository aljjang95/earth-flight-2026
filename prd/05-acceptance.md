## B. 구현 수용 기준 (미래 빌드)

단계 B MVP가 이 목록을 통과해야 “막 I 플레이어블”이다.

### B1. 온보딩

- [ ] Cesium ion 토큰 없이 이륙 가능
- [ ] 토큰 무효여도 이륙 거부하지 않음
- [ ] 프롤로그 스킵이 항상 보임
- [ ] 신규 90초 안에 조작 3개(선회·발사·락온)를 공중에서 배움
- [ ] 웹GL 실패/타일 타임아웃/지오코딩 실패 카피가 `03-live.md`와 일치

### B2. 고향 환상

- [ ] 첫 이륙 도시가 고향으로 저장
- [ ] 첫 킬 스탬프에 도시명이 있음
- [ ] 서울·대구·부산이 실좌표 (v1.3.4 `LOCATIONS` ±0.01°)

### B3. 락온 DNA

- [ ] 전방 원뿔 밖에서 충전 안 됨
- [ ] Hard LOCK 임계 0.82 ±0.02
- [ ] LOCKING 중 코너 시안, hard에서 골드 **또는** 동등한 형태 변화
- [ ] 자동 풀락 없음

### B4. 전투 가독

- [ ] 플레이어·적 탄흔이 보임
- [ ] 적 미사일이 보임
- [ ] 플레어가 유도에 영향을 줌
- [ ] 기본 카메라 3인칭, 기체 실루엣 보임

### B5. 막 I

- [ ] 대구 튜토리얼 클리어 가능
- [ ] 서울 요격 승리/패배 분기
- [ ] 부산 방어 + KRAKEN 패턴이 항구 저고도와 결합
- [ ] GHOST-1 사망 시 브리핑/라디오 변화
- [ ] 비트 사이 ≈1.15s 숨고르기

### B6. 경제 윤리

- [ ] 다이아로 HP/DPS/락온을 살 수 없음
- [ ] `다이아 +30 미리보기` 없음
- [ ] 레이스·이지스 신규 해금이 다이아 필수 아님
- [ ] 파일럿 레벨이 데미지 계수가 아님

### B7. 공허·실패

- [ ] 목표 0 스폰 시 출격 시작 안 함
- [ ] 일시정지 → 기지로 시 비트 중간 세이브 안 함 (명시된 대로)
- [ ] 구세이브 마이그레이션 실패 시 침묵 초기화 없음

### B8. 1.0 추가 (단계 C)

- [ ] 5막 + 고향 동적 최종전
- [ ] 타격·엄호 원형
- [ ] 스타일 + 코러스 적응 버킷 최소 2
- [ ] 라이벌 3 (KRAKEN, PARADE, SILENCE) + MIRROR
- [ ] 고스트 리플레이 1종

## D. PRD 일탈 기록

구현이 이 기획과 달라지면 코드 주석 또는 커밋에 `prd/` 경로와 이유를 남긴다. 워크스페이스 규칙: 스펙 일탈은 추적 가능해야 한다.

알려진 선행 일탈 (인정):

- 메인 브랜치 v1.3.4는 아직 이 기획을 구현하지 않음.
- v5.2는 시드니를 최종 전구로 둠 → 1.0은 고향 엔딩으로 재정의.
- v1.3.4 다이아 기체는 레거시. 소유자는 박탈하지 않음.
