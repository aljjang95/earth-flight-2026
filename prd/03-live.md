## 1. 멀티플레이어

웹 Cesium 전투의 정직한 한계: 64인 전장은 목표가 아니다. **에이스는 소수**다.

### 1.0 — 비동기 고스트 (캠페인 병행 가능)

- 출격 리플레이를 입력 스트림으로 저장 (1–2Hz 포즈 + 발사 이벤트).
- 친구 코드/링크: “이 리플레이가 라이벌”.
- 내 하늘에 고스트 기체가 같은 경로를 난다. 직접 락온은 1.1.
- 실패 시: 리플레이 없음 → 모드 숨김이 아니라 “아직 유령이 없다. 먼저 떠라”.

### 1.1 — 에이스 듀얼 (PvP)

- 1v1, 선택적으로 2v2. 맵은 **랜드마크 아레나** (한강, 도쿄 만, 골든게이트, 시드니 하버).
- 규칙: 스톡 1 또는 5분. 무기 밸런스는 캠페인과 동일 테이블. 유료 스탯 0.
- 락온·플레어·마스크 전부 통용.
- 레이스 은신은 실루엣 왜곡만. 완전 비가시 금지.
- 매칭: 레이턴시 우선. 800ms+면 고스트 듀얼로 폴백 제안.
- 트롤: 조기 추락 반복 시 그 세션 종료, MMR 미반영.

### 2.0 — 편대 작전 (PvE)

- 2–4인 동일 전구. 호스트의 도시.
- 역할: 요격(케스트럴), 타격(바이퍼), 방패(해리어), 리페어(이지스)가 자연스럽게 맞음.
- 전멸 시 호스트만 재시작 투표.
- 음성은 외부(디스코드). 인게임은 핑: 적/나/집결.

### 하지 않는 것 (1.x)

- 오픈 월드 MMO 지구.
- 페이 투 스킵 매칭.
- 상대 고향을 조롱하는 킬 카피 (실재 지명 + 혐오 결합 금지).

## 2. 기술 전략

### 2.1 제품 형태

**Horizon 1.0 = 브라우저.** 설치 없는 이륙이 기둥 P5다.

권장 스택 (v5.2가 이미 가리킴):

- Vite + TypeScript 모듈 (`src/flight.ts`, `combat.ts`, `world.ts`…).
- CesiumJS 1.125+ World Terrain.
- 기본 영상: Esri World Imagery (토큰 없음).
- 선택 업그레이드: Cesium ion → 지형 정밀 + Google Photorealistic 3D Tiles.
- 품질: high / medium / low. 실제 GPU는 high 기본. SwiftShader는 low 30fps. v5.2 “FPS 떨어져도 조명 자동 OFF 금지”를 시각 서약으로 유지할지 여부는 기기별 옵션으로 — **자동으로 도시를 못생기게 만들지 말 것**. 사용자가 내린다.

메인 `v1.3.4` 단일 `play.html`은 프로토타입. 1.0 구현은 모듈 트리를 채택하고 프롤로그·락온 DNA만 이식한다.

### 2.2 토큰 정책 (온보딩 최우선)

v1.3.4: 토큰 없으면 이륙 불가 → **D0 학살**.

1.0 규칙:

1. 토큰 없이 Esri 위성 지구로 즉시 이륙.
2. 격납고에 “도시를 건물로 키우기” 선택 토큰 필드. 거절해도 캠페인 100% 플레이 가능.
3. Photorealistic 실패/15s 타임아웃 → OSM Buildings 또는 위성만. HUD MAP 백엔드 표기는 정직.

### 2.3 성능 예산

| 타깃 | fps | 적 기체 | 이펙트 |
| --- | --- | --- | --- |
| Desktop high | 60 | 8–10 | 트레이서, 콘트레일, 블룸 |
| Desktop medium | 45 | 6–8 | 콘트레일 축소 |
| Mobile | 30 | 4–6 | 포인트 탄흔 허용 |

동시 폭발 엔티티 상한. 콘트레일 점 남발(현행 random entity add)은 풀링.

### 2.4 치팅 · 시드

싱글은 로컬. 듀얼 1.1부터 서버 권위 포즈 또는 리플레이 서명. 이 기획 범위의 구현 세부는 서버 선정 전 “리플레이 검증 가능”만 요구.

### 2.5 라이선스 · 윤리 테크

- 실기체 형상의 상표/실명 F-22 등 사용하지 않음. 스패로우·케스트럴은 오리지널.
- 실재 도시 파괴 비주얼 금지.
- Cesium/Google/Esri 크레딧은 현행 `#mapCredit`처럼 유지.

### 2.6 하니스 (있는 경우)

v5.2 supervisor/orchestrator는 **개발 루프**이지 플레이어 기능이 아니다. QA `/?qa=1` 스킵 튜토리얼은 유지. 플레이어 빌드에서 하니스 독 숨김.

## 3. 온보딩

### 3.1 첫 실행 스크립트 (목표 90초)

1. 타이틀 **EARTH FLIGHT / ACE HORIZON** (현행 그라데이션 보존).
2. 콜사인 3택 또는 커스텀 12자.
3. 도시: 지오 제안 / 대구 / 서울 / 더보기. 기본 추천 카피: “여기부터 고향이 된다.”
4. 토큰 없이 **이륙하기**.
5. 프롤로그 (스킵 노출). 착지는 선택한 도시.
6. 공중 튜토리얼 90초: 선회 → 기수 → 발사 → 락온 원뿔에 넣기. 벽 텍스트 없음.
7. 첫 적 2기. 첫 킬 시 스탬프 `FIRST BLOOD · {CITY}`.
8. 격납고로. 캠페인 막 I 카드가 빛난다.

`/?qa=1`은 이 전체를 스킵 (하니스).

### 3.2 튜토리얼이 가르쳐야 하는 것 / 아닌 것

가르침: 롤이 선회다, 락온은 기수, 미사일은 hard LOCK, 지면에 가까우면 아프다.  
안 가르침: 경제, 시즌, 모든 기체 스킬. 스킬은 첫 캠페인 비트2에서 F 프롬프트.

### 3.3 복귀 유저

- 세이브 있으면 프롤로그 자동 스킵.
- “이어하기 · 자유 비행 · 공중전”.
- v2 세이브 마이그레이션 실패 시 골드 1200 새 파일 + “기록 일부를 못 읽었다” — 조용히 초기화 금지.

### 3.4 모바일 첫 경험

- 가로 권장 배너, 강제 잠금은 기기 정책에 따름.
- 세이프 에어리어 현행 유지.
- 토큰 붙여넣기는 모바일에서 지옥 → 더욱 토큰 선택화가 온보딩이다.

### 3.5 공허/에러 카피

| 상태 | 카피 |
| --- | --- |
| 웹GL 없음 | “이 브라우저는 하늘을 못 연다. 최신 Chrome/Edge를 켜라.” |
| 타일 타임아웃 | “위성은 늦다. 지형만으로 이륙한다.” |
| 지오코딩 실패 | “좌표를 못 찾았다. 수도에서 이륙한다.” |
| 토큰 무효 | “토큰을 읽지 못했다. 위성 지구로 계속.” (이륙 거부 금지) |

## 4. 라이브옵스

### 4.1 월드 프론트 (2.0, 설계는 지금)

격납고 지구본에 주간 전선. 커뮤니티 클리어량으로 도시를 탈환한다.

- 주 1회 로테이션, 수요일 18:00 KST.
- 그 주 도시는 작전 카드 보너스 XP·스킨 조각.
- 내러티브: 코러스가 전자파가 밝은 도시를 옮긴다. 메타 픽은 실제 이벤트와 무관한 픽션 스케줄.

1.0에서는 프론트 UI만 정적 “다음 시즌” 티저여도 된다. 시스템이 없으면 지구본을 거짓으로 깜빡이지 말 것.

### 4.2 시즌 패스 (코스메틱)

- 무료 트랙: 스탬프, 킬마크.
- 유료 트랙: 도장, 콘트레일 색, 격납고 음악, 프롤로그 스킨.
- **락온 속도, HP, 골드 배율 금지.**

### 4.3 이벤트 출격

예: “한강 나이트 레이드” 72시간. 기존 서울 미션의 야간 리피부. 신규 맵 필수 아님.

### 4.4 커뮤니케이션

패치 노트는 도시와 에이스 이름으로. “버프 +5%”가 아니라 “KRAKEN이 항구에서 더 낮게 난다”.

### 4.5 운영 루프

- 주간: 프론트 도시, 버그픽.
- 시즌(6–8주): 라이벌 1, 도장 세트, 짧은 라디오 로그.
- 금지: 에너지 시스템이 출격을 막는 것. 일일 보상은 있어도 **출격 티켓은 없음**.

## 5. 과금 · 마케팅

### 5.1 원칙

Ace Horizon의 돈은 **정체성**이지 승률이 아니다. 스트리머가 첫 방송에서 P2W를 말하면 기둥 P6 실패.

### 5.2 팔 것

- 시즌 패스
- 도장/콘트레일/콜사인 테두리
- 서포터 팩 (크레딧 + 스킨, 스탯 0)
- 나중에: 사운드트랙, 아트북

### 5.3 안 팔 것

- 기체 스탯, 락온, 플레어 탄수, XP 부스터가 승률에 닿는 형태
- 가챠 기체
- 광고 제거를 위해 전투 중 전면 광고 (격납고 선택 광고도 1.0 비권장)

### 5.4 현행 상점의 처분

| v1.3.4 | 1.0 |
| --- | --- |
| 기체 골드 구매 | 유지 + 업적 대체 경로 |
| 레이스 90◆, 이지스 25◆ | 삭제. 업적/캠페인 해금 |
| 회복제 120G | 유지. 전투 중 상점은 없음 |
| 다이아 +30 미리보기 | 삭제 |

### 5.5 바이럴 루프

공유 단위는 **실재 랜드마크가 보이는 킬캠**. 워터마크 `ACE HORIZON · BUSAN`. 1.0은 수동 스크린. 1.1 킬캠 5초 저장.

지오 자랑은 허용, 실제 주소 정밀 공유는 하지 않음 (활주로 좌표 반올림).

### 5.6 포지셔닝 문장

- KR: “에이스 컴뱃, 그런데 무대가 지구고, 활주로가 우리 동네다.”
- EN: “Ace Combat over the real Earth. Your city is the stage.”
- 금지: “Cesium demo”, “open world MMO jet”.

## 6. 플랫폼 · 연령

- 웹 1.0. PWA 아이콘은 현행 파비콘 계열.
- 스토어 래핑(Steam/iOS)은 1.1+ 배포 문제. 비행 모델 변경 이유 아님.
- 연령 13+. 실재 테러 미러링 이벤트 안 함. 픽션 코러스만.
