# 02 — 시스템 디자인 (루프 · 비행 · 전투 · 미션 · 진행)

관련 코드 DNA: `play.html` `flight`, `spawnWave`, 진행형 락온, `RANKS`, `CRAFTS`, `SAVE_KEY earth-flight-progress-v2`  
v5.2: `HARD_LOCK = 0.82`, `LOCK_CONE = 0.36`, `WAVES_PER_THEATER = 3`, `MissionKind`

숫자가 있는 규칙은 **밸런스 초안**이다. feel DNA(락온 원뿔, 숨고르기, 3인칭 체이스)를 깨는 패치는 기획 변경으로 취급한다.

---

## 1. 코어 루프

### 1.1 인출격 (8–20분)

```
격납고에서 도시·기체·작전 선택
  → 브리핑 카드 (2–4문장)
  → 이륙 (활주로/공중 배치)
  → 비트1 접근 · 비트2 교전 · 비트3 목표/에이스
  → WAVE CLEAR 숨고르기 1.15s 문법 유지 (비트 사이)
  → 승리 스탬프 / 패배 라디오
  → 에이스 레코드 · 골드 · XP · 칭호 갱신
  → 격납고
```

### 1.2 미드 루프 (당일–주간)

기체 해금, 파일럿 레벨, 캠페인 다음 막, 랜드마크 칭호 수집, 일일 출격(선택) — “오늘 한 번, 고향 상공 기상”.

### 1.3 롱 루프 (시즌)

월드 프론트, 시즌 작전 패스(코스메틱), 라이벌 로스터 추가, 고향 스킨. 시즌은 스토리를 덮어쓰지 않고 **옆길**로 깐다.

### 1.4 세션 설계

| 세션 | 목표 |
| --- | --- |
| 90초 | 이륙 + 첫 락온 피드백 |
| 8분 | 작전 1장 클리어 가능 |
| 20분 | 캠페인 전구 1–2 + 격납고 성장 |
| 45분 | 막 하나 |

무한 웨이브 생존(구 공중전)은 별도 모드로 남긴다. 캠페인 기본 출격은 **끝이 있는 카드**다. 끝이 없으면 “에이스 영화”가 아니라 idle이다.

## 2. 비행감

장르 포지션: **Arcade-Sim Hybrid**. Ace Combat 7 아케이드에 에너지가 있는 쪽. DCS가 아니다.

### 2.1 현행 물리 DNA (유지)

`play.html` 기준:

- 롤 → `turnRate = g * tan(roll) * turnMul / speed` 협조 선회. 스틱 추가 요 없음.
- 피치 유휴 트림: 전투 `-0.05`, 자유비행 `-0.16`. 카운터 없는 지속 강하를 줄인다.
- 속도 엔벨롭: 고도에 따라 vmax 70→230 계열, 스로틀·피치 부스트.
- 실속 `stallSpeed = 28`. 바닥은 지형 + 25m, 전투 중 접촉 시 지속 대미지.
- 천장 10,000m. 우주전이 아니다.
- 애프터번 `boostMul = 1.55`, 3초, CD 8초 (스패로우).

### 2.2 1.0에서 넣는 비행 레이어

**에너지 가독성.** HUD에 숫자만 말고 에너지 상태 한 줄: `FIGHT / CRUISE / BLEED`. 저속 고기동은 선회가 달지만 실속·고도에 갚는다.

**G 블랙아웃 (라이트).** 고G 지속 시 비네트. 조작 박탈 금지(모바일 사망). 시야 20–40% 감소만.

**프로 스틱 옵션.** 에임 어시스트(건 히트스캔 0.45 보정, 현행 `d < 900 && |dh| < 0.22`)는 기본 On, 프로 Off. 끌 때 건킬 보너스 +15% XP.

**3인칭 체이스 기본.** Ace Combat 문법. 1인칭은 C 토글. v1.3.4 기본이 1인칭인 것은 랜딩 시 교정. 기체 실루엣이 보여야 에이스다.

**카메라 연출.** 속도·애프터번에 FOV punch (현행 있음). 격추 시 짧은 슬로 0.35s 후 정상. 멀미 옵션: 슬로/셰이크 Off.

### 2.3 조작 맵 (현행 유지 + 확장)

| 입력 | 행동 |
| --- | --- |
| A/D 또는 스틱 X | 롤/선회 |
| W/S 또는 스틱 Y | 피치 |
| Q/E | 러더 |
| Shift / Ctrl 또는 스로틀 ± | 가속 |
| Space | 기관포 |
| M | 유도탄 |
| G | 플레어 (신규, v5.2에 있음) |
| F | 기체 스킬 |
| 1 / R | 회복제 |
| C | 시점 |
| P | 일시정지 |
| 게임패드 RT | 기관포 (v5.2 교정 유지) |

모바일: 가상 스틱 + FIRE + M + 스로틀. 스킬/회복은 하단 액션 패널. 버튼 충돌 금지 (v5.2 플레이 품질 게이트).

## 3. 전투

### 3.1 진행형 락온 (성역)

현행 규칙을 제품 서약으로 고정한다.

- 전방 원뿔에서만 충전. ≈0.36–0.38 rad (21–22°).
- 정중앙·근거리가 충전 가속.
- 원뿔 밖 감쇠 `1.6 * dt`.
- 사거리 게이트 ≈ 3.2km.
- **Hard LOCK = 0.82.** 코너 시안 → 골드.
- Hard 미만 발사: 약유도/저피해 또는 소프트 핑(현행 lockProg < 0.35면 발사 자체 거부).
- Hard 시 유도 강하고 피해 56 vs 소프트 28 계열.

플레이어가 느끼는 문장: **락온은 조준의 보상이지 버튼의 권리가 아니다.**

### 3.2 기관포

- 주 숙련 무기. 탄흔이 **보여야** 한다 (v1.3.4 포인트 스프라이트는 부족, v5.2 트레이서 수용).
- 크리티컬 12% 현행 유지 가능하나 피드백을 CRIT 토스트 + 히트 마커로.
- 건킬 시 콤보·XP·칭호 가중. 미사일 킬의 1.5–2× XP.

### 3.3 미사일

- 기본 IR 호밍. 플레어에 풀림 (`flared`).
- 바이퍼 스킬만 더블. 상시 멀티락은 1.0 후반 파츠.
- 쿨다운 hard 2.2s / soft 2.8s DNA 유지.
- 적 미사일은 보이고, RWR이 울린다. 안 보이면 불공정.

### 3.4 플레어 / RWR / 은신

- 플레어 탄수 기체별 (스패로우 4, 케스트럴 6, 해리어 3…).
- RWR: 락 경고 방향 틱. SILENCE 에이스는 이 규칙을 고의로 깨는 예외 — 브리핑에 명시.
- 레이스 은신: 적 사격 게이트 완화 (현행 `cloaked || d < 280`). 플레이어 PvP에선 실루엣 왜곡이지 완전 투명 금지.

### 3.5 지형 엄폐 (차별화 기술)

실제 메시/타일과의 정확한 충돌은 웹에서 비싸다. 1.0은 **근사**:

- 고도 < 주변 빌딩 추정 캐노피(도시별 상수, 서울 250m, 부산 해안 180m…)이면 `TERRAIN MASK` 상태.
- 이 동안 적 레이더 미사일 유도 계수 0.35, 락 충전 적도 느림.
- 건물 충돌은 현행 지면 클램프+대미지로. 완전한 메시 충돌은 품질 프리셋 High에서만 시도.

이게 “구글 어스 위에서 에이스”의 전술 문장이다.

### 3.6 콤보 / 스타일 / 코러스 적응

**콤보:** 현행 킬 스트릭 타이머. x2 x3 토스트 유지.

**스타일 (신규):** 0–100. 증가: 건킬, 근접 통과 <150m, 마스크 중 회피, 하이 알파 선회. 감소: 미사일 스팸, 동일 회피 반복, 오사.

스타일 80+ 시 출격 종료 칭호 `HUMAN NOISE`. 코러스 적응을 1턴 늦춘다.

**코러스 적응 (라이트, 1.0):** 출격 중 플레이어 버킷.

| 버킷 | 조건 | 코러스 반응 |
| --- | --- | --- |
| BURNER | 애프터번 사용 ≥3 | 이탈 경로에 차단기 |
| MISSILE | 미사일 킬 비율 >70% | 플레어 남발·기만 |
| PERCH | 고도 >2000m 지속 | 하단 접근 에이스 |
| CANYON | 마스크 시간 김 | 고도 끌어올리기 |

UI에 “CHORUS READING YOUR BURNER” 한 줄. 읽히면 스타일로 리셋. MIRROR 보스는 이 시스템의 서사화.

### 3.7 적 AI 프로파일

v5.2 `AiMode`: intercept / guns / break / extend / rejoin.

- bandit: 단순 추적+사격 (현행에 가깝다).
- leader: 에너지 파이팅, 6시 유지 시도.
- ace: 도시 연동 특수 + 적응 버킷.
- 너무 가까운 궤도 붕괴 시 break (현행 d<320 회피 유지).

스폰: 웨이브 1은 **요격이지 매복이 아니다**. v5.2 “Wave-1 merge protection”을 캠페인 비트1 규칙으로 승격. 스폰 거리 260m 급습(v1.3.4 일부)은 튜토리얼 외 금지.

### 3.8 랭크 (무한 공중전 모드)

현행 `RANKS` 이름 유지: 훈련 → 교전 → 전장 → 제공권 → 전설 → 종말.  
캠페인 난이도는 이와 별도로 파일럿/에이스/전설 셀렉트(현행 0.75/1/1.35/1.7).

## 4. 미션 루프 상세

### 4.1 공통 HUD 목표 라인

상단 한 줄. 예:

- 요격 `BANDITS 3/8`
- 타격 `SPIRE 62%`
- 방어 `CITY 81% · 폭격기 2`
- 엄호 `CARGO 거리 12km · HP 70%`

비면: 목표 0인 상태로 스폰 금지. 스폰 실패 시 즉시 기지 귀환 + “작전이 성립하지 않았다”.

### 4.2 타격

지상 타깃 `GroundTarget` (v5.2). 건으로도 깨진다(저고도 리스크). 미사일 연성은 빠르지만 스타일 낮음. 민간 건물 오폭: 도시 타일 랜덤 페널티 금지(실제 도시 윤리). 타깃은 명확한 스피어 노드 메시/마커만.

### 4.3 방어

도시 HP 100. 적 `hunt: "city"`가 폭조준 성공 시 감소. 플레이어가 폭격기를 우선해야 하는 긴장. 도시 0 = 패배. 시네마틱으로 실제 시가지를 지우지 않는다 — HUD와 스피어 침식 이펙트만.

### 4.4 엄호

수송기는 정해진 polyline (해안선 따라). 플레이어가 너무 멀면 (`> 4km`) 경고 후 HP 가속 감소. GHOST-1이 기본 가드, 플레이어는 자유 요격.

### 4.5 보스 비트

5웨이브마다 보스(현행)는 공중전 모드에 남김. 캠페인은 **라이벌 에이스 1기 + 호위**. 체력 덩어리 스펀지 금지. 패턴이 도시와 결합해야 함.

## 5. 진행 · 경제

### 5.1 세이브

키는 `earth-flight-progress-v2` 호환 확장. 필드 추가:

```
callsign, hometownId, medals[], stamps[],
theatersCleared[], campaignAct, ghost1Alive,
styleBest, gunKills, ownedSkins[],
battlePassTier,  // 코스메틱 only
```

구세이브 마이그레이션: 골드/XP/owned 유지. 다이아로 산 레이스는 **owned 유지**(이미 산 사람 박탈 금지)하되 신규 다이아 스탯 판매 중단.

### 5.2 재화

| 재화 | 획득 | 사용 |
| --- | --- | --- |
| 골드 | 작전 클리어, 웨이브, 일일 | 기체 해금, 회복제, 파츠(스탯 미미·비과금) |
| 파일럿 XP | 킬, 건킬, 미션, 스타일 | 레벨. 레벨은 슬롯/콜사인 테두리이지 데미지 아님 |
| 다이아 | 시즌, 업적, (선택) 구매 | **스킨, 도장, 출격 연출, 패스** |
| 메달 | 업적 | 격납고 벽 |

현행 회복제 120G, 시작 골드 1200, 웨이브 클리어 `(55+wave*12)*goldMul` 은 공중전 모드 초안 유지.

**삭제:** `다이아 +30 (미리보기)` 치트 버튼. 리뷰어·유저가 경제를 장난으로 읽는다.

### 5.3 파일럿 레벨

`xpNeed = 90 + (lv-1)*70` 현행. 레벨 보상: HUD 스킨, 스탬프 슬롯, 격납고 크레딧. **HP/공격력 계수 금지.** 난이도는 셀렉트와 캠페인 막이 담당. 레벨이 DPS면 라이브가 망가진다.

### 5.4 기체 해금 (윤리)

| 기체 | 해금 |
| --- | --- |
| 스패로우 | 기본 |
| 케스트럴 | 900G 또는 캠페인 막 I 클리어 |
| 해리어 | 2200G 또는 방어 미션 3 |
| 바이퍼 | 4500G 또는 hard LOCK 킬 40 |
| 이지스 | 2800G + 윙맨 생존 5출격 (다이아 경로 삭제) |
| 레이스 | 캠페인 막 III 또는 스타일 80 달성 3회 (다이아 경로 삭제) |

스탯 페이월 재도입 금지.

### 5.5 파츠 (1.0 라이트)

출격 전 1슬롯. 예: `GUN GYRO +4% 히트박스(프로 모드 무효)`, `COOLER 미사일 CD -0.2s`, `PAINT 스타일 가시성`. 파츠도 과금 판매 금지. 골드/업적.

### 5.6 칭호 · 스탬프

랜드마크 근접(반경 도시별) + 킬 또는 통과.

예:

- `한강 에이스` 서울
- `광안 저격수` 부산
- `GOLDEN GATE` SF 엄호 클리어
- `DAEGU GHOST` 고향 대구 + 은신 킬
- `HUMAN NOISE` 스타일 80+
- `GUN ONLY` 미사일 0 클리어

칭호는 격납고와 킬피드에 표시. 이게 코스메틱 코어다.

## 6. 난이도 · 접근성

- 훈련생 0.75 / 파일럿 1 / 에이스 1.35 / 전설 1.7 유지.
- 훈련생: 락온 원뿔 10% 확대, 도시 HP 1.25×, GHOST-1 더 공격적.
- 전설: 어시스트 Off 강제 아님(옵션). 적응 버킷 더 빠름.
- 색각: 락온 시안/골드를 모양(코너 두께)으로도 구분 — 색만으로 상태 전달 금지.
- 자막, 진동 강도, 모션 저감.

## 7. 오디오 판타지

현행 WebAudio 엔진음·건·붐은 프로토타입. 1.0 최소:

- 락온 상승 피치 (LOCKING%) → hard에서 고정 톤.
- RWR 방향 틱.
- 도시별 앰비언트 한 겹 (서울 낮, 카이로 밤).
- 음성은 자막이 본편, 보이스는 있으면 좋음(2.0).

## 8. 이 문서가 깨지면 안 되는 불변량

1. Hard LOCK 0.82와 전방 원뿔.
2. 비트 사이 숨고르기 ≈1.15s.
3. 레벨이 데미지를 안 삼.
4. 실재 도시 오폭 연출 없음.
5. 건이 장난감이 되지 않음.
