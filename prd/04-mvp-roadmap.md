# 04 — MVP와 로드맵

구현이 아니라 **무엇을 어느 단계의 제품으로 볼 것인가**. 기준선은 공개 메인 **v1.3.4**. v5.2 월드 컴뱃 브랜치는 흡수 후보이지 현재 플레이어 빌드가 아니다.

우선순위 언어: P0 없으면 제품이 아님 · P1 1.0 출격 · P2 1.0 후반/1.1 · P3 2.0 환상.

---

## 1. 지금 당장 지켜야 할 자산

버리거나 “리메이크하면서 잃어선 안 되는” 것:

- 시네마틱 프롤로그 궤도 다이브와 여섯 줄 카피
- 진행형 락온 (원뿔, LOCKING%, 시안→골드, 0.82)
- WAVE CLEAR 1.15s 숨고르기
- 실좌표 도시 테이블 + 커스텀 지오코딩
- 6기체 역할/스킬 판타지 (가격 모델만 교정)
- 모바일 스틱 + 세이프 에어리어 HUD
- 한/영 혼용 톤

## 2. 단계

### 단계 0 — 기획 원본 (본 문서) ✅ 이 저장소의 이번 산출물

`prd/` 전체. 구현 없음.

### 단계 A — Playable Foundation (“토큰 없는 에이스”)

v5.2에서 가져올 것 + v1.3.4 DNA.

P0:

1. 모듈 TS 빌드 (Vite)로 `play.html` 거대 IIFE 탈출
2. **토큰 없이 이륙** (Esri 기본)
3. 3인칭 체이스 기본, 기체 보임
4. 격납고: 캠페인/공중전/자유비행 3모드
5. 가시 트레이서·적 미사일·RWR·플레어
6. 다이아 치트 버튼 삭제, 레이스/이지스 스탯 페이월 삭제
7. 튜토리얼 공중 90초 + 프롤로그 스킵
8. 웨이브1 매복 금지 (merge protection)

완료 정의: 토큰 없는 신규가 서울 상공에서 락온→격추→기지 귀환까지 막힘 없음.

### 단계 B — Horizon Campaign 0.9 (막 I)

P0/P1:

1. 막 I: 대구 튜토리얼 → 서울 요격 → 부산 방어 + **KRAKEN**
2. 작전 카드 3비트, 목표 HUD 라인
3. GHOST-1 윙맨 (사망이 브리핑을 바꿈)
4. 고향 설정 + `FIRST BLOOD` 스탬프
5. 랜드마크 칭호 최소 3 (한강, 광안, 고향)
6. 기체 실루엣 구분 (색+형태, 동일 GLB 탈출)
7. 미션 타입 요격/방어 안정. 타격/엄호는 막 II 예고 또는 나이로비 QA 맵만

완료 정의: “우리 동네 에이스” 트레일러를 막 I만으로 찍을 수 있다.

### 단계 C — Horizon 1.0

P1:

1. 5막 캠페인 + 동적 고향 최종전 CHORUS-0
2. 라이벌 PARADE, SILENCE, MIRROR
3. 타격·엄호 포함 전 미션 원형
4. 스타일 게이지 + 코러스 적응 라이트
5. 에이스 레코드 UI (콜사인, 스탬프, 건킬)
6. 품질 프리셋, 토큰 업그레이드 3D 도시
7. 경제/해금 테이블 본 기획과 일치
8. 고스트 리플레이 (1.0 멀티의 최소)

완료 정의: 리뷰어가 Ace Combat과 MSFS를 동시에 꺼내면서 “내 도시”를 말한다.

### 단계 D — 1.1 Live Lite

P2: 킬캠 공유, 에이스 듀얼 1v1, 시즌 패스 코스메틱, 이벤트 야간 리피부.

### 단계 E — 2.0 One Earth

P3: 월드 프론트 주간, 2–4인 편대, 음성 핑, 시즌 라이벌 로스터.

## 3. 우선순위 스택 (구현자가 헷갈릴 때)

항상 위부터:

1. 이륙이 되는가 (토큰, 성능, 크래시)
2. 내가 아는 도시가 보이는가
3. 락온이 손맛인가
4. 출격에 끝이 있는 이야기인가
5. 이름이 남는가 (스탬프/콜사인)
6. 그 다음 콘텐츠 양

맵 18개를 먼저 늘리고 락온이 무너지면 실패다. v5.2가 전구를 많이 깐 것은 자산이되, **도시 목록 ≠ 개쩌는 게임**.

## 4. MVP 컷 (단계 B를 MVP로 부를 때)

포함:

- 토큰 없는 이륙
- 막 I 세 출격
- 락온 DNA + 플레어 + 보이는 탄
- GHOST-1
- KRAKEN
- 고향 스탬프
- 윤리 상점
- 공중전 무한 웨이브(구모드) 잔존
- 자유 비행

제외 (고의):

- 듀얼 PvP
- 월드 프론트 실동작
- 시즌 패스 결제
- 전 기체 고유 LOD 모델 세트 (실루엣 3종이면 MVP 통과)
- 보이스 액팅
- 네이티브 스토어

## 5. v5.2 흡수 가이드

가져온다:

- `THEATERS` 좌표/날씨/미션 종류
- 윙맨, 격납고 GFX, 튜토리얼 플래그, 메달 칩
- 토큰 선택, Esri 폴백
- 하니스 QA 훅 (개발)

다시 쓴다:

- 브리핑 문장 → 코러스 세계관 (`01-gdd.md`)
- 시드니 = 최종 엔딩이 아님. 고향이 엔딩
- 다이아 기체
- 18도시 순회만이 캠페인인 구조 → 5막 서사

남기지 않는다:

- 플레이어 대면 하니스 독
- 자가버프 루프가 체감 난이도를 몰래 바꾸는 것 (텔레메트리 밸런스는 개발 빌드만)

## 6. 콘텐츠 생산 순서 (캠페인)

1. 대구 튜토리얼 비트 (조작)
2. 서울 요격 (장관 + 락온 교과서)
3. 부산 방어 + KRAKEN (라이벌 교과서)
4. 파리 PARADE (마스크 교과서)
5. 카이로 SILENCE (RWR 교과서)
6. 막 IV MIRROR (적응 교과서)
7. 시드니 클라이맥스
8. 고향 CHORUS-0
9. 나머지 전구는 4종 미션 템플릿으로 채우되, 라이벌 없는 도시는 **장관+미션 타입**으로 차별

## 7. 인원/의존 (참고, 일정 추정 아님)

핵심 의존: Cesium 타일, 기체 메시 3+, HUD 아트, 한 명의 시스템 디자이너가 락온 불변량을 지킴.  
막 I MVP는 엔진 교체 없이 웹에서 닫힌다.

## 8. 킬 스위치

다음이면 출시 이름을 1.0이라 부르지 않는다.

- 토큰 필수
- 1인칭만 / 기체 안 보임
- 웨이브 전멸만 있는 캠페인
- 다이아가 DPS
- 엔딩이 시드니에서 끝나고 고향이 없음
- 락온이 자동 풀락
